ProteomIQon - MzMLToMzLiteToIonMobility

i Tool Description Purpose and functionality of the tool

MzMLToMzLiteIonMobility converts mzML files from ion mobility instruments such as the Bruker timsTOF into mzlite files.

? How does MzMlToMzLite work? Step-by-step explained
    1. MzML to Mzlite

      In these files every peak carries an ion mobility value next to its m/z and intensity, and the tool keeps that value in the mzlite. It is the ion mobility counterpart of MzMLToMzLite, which also explains how to get mzML from raw files and what mzlite is. The tool reads the same parameter record as MzMLToMzLite.

    2. How to get MzML

      To get mzML from vendor raw files, use MSConvert. On Galaxy.eu runs msconvert in the browser without a local install.

    3. Important to know

      The spectra are written with their m/z, intensity and ion mobility arrays as they are in the mzML, and Compress decides how those arrays are stored.

<> Inputs

These inputs are needed to execute the tool:

Flag Meaning Comes from
-i one or more mzML files, or a directory that is searched for *.mzML and *.mzml (not recursive) MSConvert
-o the output directory, created when missing -
-p the parameter file in JSON Github ProteomIQon Core
-c number of files converted at the same time, default 1, no effect on a single file -
-f switch: rewrite every input file in place and remove " in vendor raw files -

  • The reader fails on mzML without ion mobility data.

  • -f every input file in place and removes the string quot, for mzML exports where that string breaks the XML reader.

  • The tool writes one run.mzlite per input into the output directory.

  • Spectra with an MS level other than 1 or 2 stop the conversion with an error. Scan times are stored in minutes.

  • The mzlite is read by PeptideSpectrumMatching, PSMBasedQuantificationTIMs and MSFragger. The output directory also receives MzMLToMzLite_log.txt and one run_log.txt per input.

! Parameter file
Parameter Default Meaning
Compress Compression.NoCompression Compression of the peak arrays in the mzlite. Compression.ZLib and Compression.NumPress are the other options, Compression.NumPressZLib combines both.
StartRetentionTime None With Some t, only spectra with a scan time above t are copied. The comparison uses the time unit of the mzML file.
EndRetentionTime None With Some t, only spectra with a scan time below t are copied, same unit as above.
MS1PeakPicking PeakPicking.Centroid (CentroidizationMode.Wavelet ms1Wavelet) Same field as in MzMLToMzLite. The default file carries the wavelet record shown in the script below, and the MS1 peaks are copied as they are.
MS2PeakPicking PeakPicking.Centroid (CentroidizationMode.Wavelet ms2Wavelet) Same field as in MzMLToMzLite, with padding settings in the default file. The MS2 peaks are copied as they are.
.exe Installing and executing the tool Execution of the tool
  1. Installing

    Install the Tool with the following command inside the choosen Command-Line

    dotnet tool install --global ProteomIQon.MzMLToMzLiteIonMobility
  2. Execute

    • Convert one run

      proteomiqon-mzmltomzliteionmobility -i path/to/run.mzML -o path/to/output -p path/to/TIMsMzMLtoMzLiteParams.json

    • Convert multiple runs

      proteomiqon-mzmltomzliteionmobility -i path/to/run1.mzML path/to/run2.mzML path/to/run3.mzML -o path/to/output -p path/to/TIMsMzMLtoMzLiteParams.json -c 3
  3. Help

    If the execution of one or multiple runs failed, use the -f flag to get rid of the quot part that is a common leftover in the raw vendor files

    proteomiqon-mzmltomzliteionmobility -i path/to/run.mzML -o path/to/output -p path/to/TIMsMzMLtoMzLiteParams.json -f
  4. All Flags 
    proteomiqon-mzmltomzliteionmobility --help
