ProteomIQon - JoinQuantPepIonsWithProteins

Tool Description

A .quant file knows the intensity of every peptide ion, and a .prot file knows which protein group each peptide sequence belongs to and how confident that assignment is. JoinQuantPepIonsWithProteins puts the two together.

What's happening?

It reads the protein table, splits its semicolon separated peptide list into one row per sequence, and attaches the protein group and its q-value to every quantified ion with the same sequence. The result is one .quantAndProt file per run, which is what LabelFreeProteinQuantification and LabeledProteinQuantification read.
