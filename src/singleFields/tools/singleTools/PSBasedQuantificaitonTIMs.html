ProteomIQon - PSMBased Quantification TIMs

Tool Description

PSMBasedQuantificationTIMs is the PSMBasedQuantification variant for timsTOF runs.

What's happening?

On these instruments a peptide ion is a peak in two dimensions, retention time and ion mobility, so the tool extracts an intensity grid over that plane around every identification instead of a one dimensional ion chromatogram. By default it locates the peak on the grid with a Gabor filter (a Gaussian envelope multiplied with a cosine wave, tuned in size, width, frequency and angle), then fits and integrates it. The output has the same layout as the output of PSMBasedQuantification, so the downstream tools do not care which of the two produced it.
