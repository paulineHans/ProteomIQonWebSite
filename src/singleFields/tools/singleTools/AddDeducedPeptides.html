ProteomIQon - Add Deduced Peptides

Tool Description

AddDeducedPeptides takes the protein groups of the combined inference and assigns them to every peptide present in each aligned .quant file, so that JoinQuantPepIonsWithProteins can join the transferred quantifications to proteins. After alignment and AlignmentBasedQuantification a run's .quant file holds peptides that were never identified in that run, so the run's .prot file from ProteinInference does not list them.

What's happening?
  1. The tool reads all .prot files as one combined inference and does not pair them with the .quant files by name. This only works when ProteinInference ran over all runs together (GroupFiles set to true), because then every run's .prot file carries the same scores and Q-value for a protein group.
  2. If a protein group turns up with different scores, the tool stops with the message "If you are running this tool please infer proteins over all files".
  3. For every input .quant file the tool writes a corresponding .prot file into the output directory, a tab-separated table with the columns of a ProteinInference result.
  4. Each protein group keeps its scores and Q-value, and its PeptideSequence column lists only the peptides that occur in that .quant file. Protein groups without any peptide in the file are dropped.
  5. JoinQuantPepIonsWithProteins reads the new .prot file together with the scored .quant file of the same run.
Inputs

These inputs are needed, to execute the tool:

Flag Meaning Comes from
-i one or more aligned .quant files, or directory that is searched for *.quant AlignmentBasedQuantification
-ii one or more .prot files, or a directory that is searched for *.prot Protein Inference
-o the output directory, created when missing
  • For AddDeducedPeptides there is no parameter file needed.
  • Delete an existing output .prot file before a rerun, because the tool appends to it
  • Logs go to AddDeducedPeptides_log.txt.
Outputs
Column Description
ProteinGroup Protein Identifier Collection
PeptideSequence List of all peptides assigned to this protein group
Class Peptide Evidence Classes (C1A, C1B, C2A, C2B, C3A, C3B) which define how a peptide has been assigned to its corresponding protein
TargetScore Target Score calculated based on the individual peptide scores of PSM
DecoyScore Decoy Score calculated based on the individual peptide scores of PSM
QValue Q-value (False-Discovery-Rate) for every identified protein
