ProteomIQon - Add Deduced Peptides

Tool Description

After alignment and AlignmentBasedQuantification a run's .quant file holds peptides that were never identified in that run, so the run's .prot file from ProteinInference does not list them. AddDeducedPeptides takes the protein groups of the combined inference and assigns them to every peptide present in each aligned .quant file, so that JoinQuantPepIonsWithProteins can join the transferred quantifications to proteins.
